# 🎲 Dice Game - React

A fun and interactive Dice Game built with **React.js**, **Vite**, and **Tailwind CSS**. Test your luck by selecting a number and rolling the dice. If your selected number matches the rolled dice, you earn points. Otherwise, you lose points.

## 🎯 How to Play

1. Click **Play Now**.
2. Select any number between **1 and 6**.
3. Click on the dice to roll.
4. If the rolled number matches your selected number:
   - ✅ Score increases.
5. Otherwise:
   - ❌ Score decreases.
6. Keep rolling and try to get the highest score.
